# College Skill Exchange Platform (CSEP)

**Learn a Skill • Share a Skill**

CSEP (College Skill Exchange Platform) is a frontend-based web application designed to help college students explore different skills, discover student projects, connect with other learners, and grow together.

The platform provides a common space where students can explore learning opportunities, participate in discussions, and collaborate with fellow students.

## 🚀 Features

- **Home Page:** Introduction to the platform and its features.
- **Student Registration:** Registration form with input validation.
- **Login Page:** Login functionality using browser local storage.
- **Dashboard:** Displays student information and learning journey.
- **Explore Skills:** Browse and search different skills.
- **Skill Details:** View skill descriptions, topics, and learning resources.
- **Student Projects:** Explore sample student projects.
- **Project List:** Search and filter projects by category.
- **Community:** Create discussions, like posts, comment, and explore study groups.
- **Responsive Design:** Layouts designed to adapt to desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling and responsive layouts
- JavaScript – Interactivity and functionality
- Local Storage – Storing demo registration and discussion data

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code for a better development experience.

The website uses CSS media queries and flexible layouts to adapt to different screen sizes.

It is designed for:
- Desktop
- Laptop
- Tablet
- Mobile devices

## ⚠️ Project Limitations

This project is currently a frontend demonstration built using HTML, CSS, and JavaScript.

- No backend or database is connected.
- Registration and login use browser local storage.
- Community posts are stored locally in the browser.
- Sample projects, events, and student information are demonstration content.
- Real-time communication and cross-device data sharing are not implemented.
